# 🌸 Iris Flower Classification

A Machine Learning web application that predicts the species of an Iris flower based on its sepal and petal measurements.

## 📌 Project Overview

This project uses three Machine Learning classification algorithms to predict the species of an Iris flower:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes

The application is developed using **Python** and **Streamlit** and provides an interactive interface for making predictions.

## 🌸 Iris Species

The model predicts one of the following Iris species:

* Iris-setosa
* Iris-versicolor
* Iris-virginica

## 📊 Input Features

The application uses four features:

* Sepal Length (cm)
* Sepal Width (cm)
* Petal Length (cm)
* Petal Width (cm)

## 🤖 Machine Learning Models

### Logistic Regression

A classification algorithm used to predict the Iris species based on the input measurements.

### K-Nearest Neighbors (KNN)

Classifies a flower based on the species of its nearest data points.

### Gaussian Naive Bayes

Uses probability-based classification to predict the flower species.

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/iris-flower-classification.git
```

### 2. Open the project folder

```bash
cd iris-flower-classification
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your browser.
